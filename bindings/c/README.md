# Wickra Backtest — C / C++

---

The stable **C ABI** for the [wickra-backtest](../../README.md) engine, and the
hub every non-native binding (C#, Java, Go, R) calls through. The same source
compiles as C and C++ (the header is `extern "C"`), and the report is
byte-identical to every other binding.

## Build

```bash
cargo build -p wickra-backtest-c           # debug   -> target/debug
cargo build -p wickra-backtest-c --release # release -> target/release
```

This produces a shared library (`wickra_backtest.dll` / `libwickra_backtest.so`
/ `.dylib`), a static library, and `include/wickra_backtest.h` (generated by
cbindgen).

## API

```c
#include "wickra_backtest.h"

int  wickra_backtest_run(const double *open, const double *high,
                         const double *low, const double *close,
                         const double *volume, const int64_t *time,
                         uintptr_t n, const char *spec_json,
                         double capital, char **out_json);
void wickra_backtest_free_string(char *s);
const char *wickra_backtest_version(void);
```

`wickra_backtest_run` writes the report JSON to `*out_json` (free it with
`wickra_backtest_free_string`) and returns `WICKRA_BT_OK` (0), `WICKRA_BT_ERROR`
(1, message in `*out_json`) or `WICKRA_BT_PANIC` (2). No panic crosses the
boundary.

## Example

See [`examples/c/example.c`](../../examples/c/example.c). Build and run it (on
Windows, MinGW links the MSVC DLL by exact name):

```bash
cargo build -p wickra-backtest-c
gcc examples/c/example.c -I bindings/c/include \
    -L target/debug -l:wickra_backtest.dll -o example   # Linux/macOS: -lwickra_backtest
PATH="$PATH:target/debug" ./example                     # dll on the loader path
```

The same source compiles as C++ with `g++ -x c++ …`.
